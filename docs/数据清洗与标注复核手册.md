# 中医药命名实体识别数据清洗与标注复核手册

本手册记录训练集、验证集和测试集共用的清洗流程，以及历轮复核中形成的标注口径。项目标注用于识别原文中的实体。判断以原文、上下文、标注规则和可核实的资料为依据，模型预测只用于数据定稿后的模型评估。

## 数据从哪里来，在哪里修

原始数据为 `data/medical.train`、`data/medical.dev`、`data/medical.test`，采用字符级 BIO 格式。`prepare_data.py` 把它们转换为 `data/processed/` 下的三个 JSONL 文件，并生成标签列表和数据审计报告。

- **实体修订**写入 [annotation_revisions.json](../data/annotation_revisions.json)。以样本 ID 为键，`input` 和 `output` 保存原始 BIO 转换结果，`revised_input` 和 `revised_output` 保存完整裁定结果。对同一样本继续修订时，更新后两个字段，并保留其他已确认实体。
- **整条样本隔离**写入 [split_exclusions.json](../data/split_exclusions.json)，记录样本 ID 和理由。可靠原文到手后，先重建标注与偏移，再撤销隔离。
- **裁定依据**写入复核清单，记录数据集、样本 ID、原实体、问题、处理动作、新实体及来源。清单中应区分已裁定和已应用，保留当时的原文及标注快照。

样本 ID 由原始 BIO 的样本顺序生成。改动原始文件的分段或顺序后，要重新核对 ID 与原文的对应关系。正式 JSONL 由脚本重建，持久化修订通过上述配置进入生成流程。

## 在 prepare_data 阶段解决的问题

1. **转换及结构校验**。保留原文空格、全半角、标点和换行分段信息所决定的样本边界。检查 BIO 标签合法性、I 标签的前置衔接和实体字段。偏移从 0 开始，区间左闭右开，必须满足 `input[start:end] == text`。每个实体使用连续区间，平面标注不允许重叠和嵌套。
2. **重复与泄漏**。相同原文跨训练与评估集出现时，从训练集排除。验证集和测试集同文时保留验证集版本。训练集同文同标只留一条，同文异标组先排除并审计。验证集内部重复、仅标点或空白不同的近重复，以及同文漏标，须另行复核。例如训练样本 `train-000643` 与验证样本 `dev-000481` 仅一处标点不同，裁定保留验证版本。归一化可用于找候选，正式实体仍按原文定位。
3. **应用语义裁定**。先核对修订所依据的原文和原标注，再写入替换结果和隔离名单。修订未匹配、集合变空或修订后出现跨集同文时，排查原因后再生成。自动校验适合发现结构错误与候选，词义、边界和药名勘误需要上下文裁定。
4. **核验输出**。比较生成前后的样本数、实体数、无实体样本数及各类分布。逐条确认修订的完整实体列表与隔离名单。原句确实没有目标实体时可保留为空数组。文本残缺且药名或病名无法可靠复原时，隔离整条，避免把残缺表达留作负例。

## 三个数据集统一采用的标注口径

允许类别为中药、方剂、临床表现、中医证候、中医诊断、西医诊断、中医治则、中医治疗、西医治疗、其他治疗。同一词可以随句中作用改变类别，复核时要定位到具体出现位置。

| 问题 | 裁定口径与实例 |
|---|---|
| 西医检查检验 | **西医的各种检查、检验结果都不要标注**，包括验血、验尿、影像、心电图和西医体检结果。血常规正常、黄疸指数增高、复查腹水和胸水基本消失均属此类。原文明示由检查确诊的疾病，按诊断语境标注，例如“经 CT 检查确诊为肝硬化胸水伴腹水”中的确诊诊断。 |
| 病名与临床表现 | “辨证为呃逆”中的“呃逆”是中医诊断，“呃逆即止”中的“呃逆”是临床表现。按项目口径，原文明确记录的正常、缓解或消失状态也可属于临床表现，西医检查检验结果仍按排除规则处理。 |
| 中医病名、证候与西医病名 | 中医病名和证候按各自在句中的作用标注，例如“津亏肠燥气滞证”是中医证候。原文明示“功能性便秘”“慢性功能性便秘”时，保留完整名称并标为西医诊断。“黄疸性肝炎”“急性黄疸性肝炎”按完整西医诊断处理。明确并列中医病名时，“黄疸”可标为中医诊断。 |
| 并发症与病机 | 西医诊断或住院病名中的“腹水”可标西医诊断。病机叙述中的腹水可按临床表现处理。句中确有“臌胀”等中医病名时，结合上下文判断其边界和类别。 |
| 中药和方剂边界 | 保留属于名称的炮制、来源等前缀，如“煅牡蛎”。本批裁定保留“四逆五苓散加减”的完整方剂表达。“配”、用量、计量单位及连接标点不作为中药实体。“海花”按已确认勘误更正为“海龙”并标中药，同时重核位置。 |
| 中医治则、证候与疗法 | 看词在原句中的功能。“湿重于热”描述辨证结果，标中医证候。治则如“健脾化湿”表达施治原则。具体实施的针刺或中药药液灌肠按中医治疗处理。 |
| 食疗 | 原文只写“食疗”，缺少辨证施膳、药膳组成等证据时，按项目统一口径标“其他治疗”。本轮涉及的胃炎和功能性便秘语料共 9 处采用此口径。明确中医食疗的样本另按语境裁定。 |
| 结肠水疗 | 依据干预内容判定。桃核承气汤加减结肠水疗的原始研究明确使用方剂药液灌肠，本批对应实例标中医治疗。另有语料明确写作独立非药物水疗，标其他治疗。 [原始研究方法 1.7](https://cacm.jp.kxsz.net/article/doi/10.13422/j.cnki.syfjx.20200325?tab=2) |

## 从筛查到裁定

先按训练、验证、测试三套数据做结构和重复检查，再筛查同词异标、同文漏标、边界异常、易混类别、检查指标误标及疑似残字。筛查命中后逐处回到原句。例如同句两次出现“便秘”，可分别承担诊断和病情改善描述，不能用词典把两处统一替换。复核训练集时也应用同样规则，避免模型从训练数据学到与评估集冲突的口径。

有疑义时优先查原始论文的方法、原始医案、正式诊疗指南或专业共识。文献用于支持医学术语和干预内容，实体分类及边界依项目规则确定。通用本草资料可以证实某药名存在，具体处方的缺字仍需要原文证实。摘要只写联合“食疗”时，应明确证据所能支持的范围。 [慢性便秘临床路径](https://www.cma.org.cn/art/2018/6/8/art_1542_263.html) · [肝硬化腹水中西医结合诊疗专家共识](https://csg.cma.org.cn/csg/a/bh4gz5) · [黄芪汤联合食疗原始研究摘要](https://tjzhongyiyao.tjutcm.edu.cn/tjzyy/ch/reader/view_abstract.aspx?file_no=20190214&flag=1)

本轮隔离 `train-002845` 的“萆”、`train-004952` 和 `train-004982` 的“虫”、`test-000336` 的截断“便秘型”。这些样本保留在源数据与审计中，便于后续溯源。

历轮记录见 [中药与临床表现复核](中药与临床表现标注复核清单.json)、[训练集标注质量审计](训练集标注质量审计.json)、[40 条剩余候选裁定](剩余标注人工裁定清单.json)、[全量一致性筛查](全量标注一致性复核.json)、[50 处文献复核及后续 13 处经验裁定](50处待核实文献裁定.md)。这些批次存在承接关系，统计不应直接相加。

## 重建、核验与重训

在仓库根目录执行：

```bash
python3 prepare_data.py
python3 -m unittest discover -s tests -p test_data_metrics.py
git diff --check
```

生成后核对 [数据审计报告](../data/processed/data_audit.json) 中的源文件摘要、修订 ID、排除记录和数据集统计。本轮应用的基准是 **148 条样本的 157 处标注变更**，另隔离 **4 条**。正式数据为训练集 **5,170** 条、验证集 **655** 条、测试集 **656** 条。该轮覆盖全量结构与同词类别一致性筛查，逐句语义复核尚未覆盖所有样本。

使用更新后的训练集重新训练，并以同版验证集与测试集重新预测和评估。旧 `outputs` 记录对应当时的模型、标注和评分口径，应用新裁定后应新生成预测和指标。评估端单独处理模型偏移错误：实体文本在原文中唯一命中时可回填偏移，多次命中时保留错误记录。这个评分处理不写回金标。比较不同训练轮次时应注明数据版本，若要单独衡量模型变化，应把两个模型放在同版评估集上重跑。 [训练与评估命令](../README.md)
