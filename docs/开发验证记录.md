### 测试证明了什么

- BIO 字符保留、边界解析、训练去重与冲突隔离符合预期。
- 提示和 padding 不参与损失，真实 EOS 保留监督。
- 计分采用完整实体匹配，非法输出和重复 ID 不会被静默忽略。
- 相同原文搭配不同真实标签时，生成结果相同，生成不依赖真实答案。
- 微型模型可以执行单步 LoRA 训练、保存 adapter，并在新进程重载评估与预测。

这些测试不证明模型已学到有效的识别能力，也未充分覆盖多个 checkpoint 之间的最佳模型选择。
